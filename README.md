Customer Churn Analysis using SQL, Power BI, and Python

Project Overview

This project is a comprehensive analysis of customer churn, carried out by combining SQL, Power BI, and Python. The main objective was to understand customer behavior, identify churn patterns, and predict customers at risk of leaving. The project demonstrates how data engineering, analytics, and machine learning can be integrated into a single workflow to generate business value.

ETL and Data Exploration

The project began with creating a database and designing relational tables to store customer information. SQL was used to perform data extraction, transformation, and loading (ETL), along with exploratory data analysis. This step ensured that the dataset was structured, cleaned, and ready for further analysis.

Interactive Dashboards with Power BI

To transform the raw data into meaningful insights, Power BI was used to design interactive dashboards. Using DAX (Data Analysis Expressions), calculated columns and measures were created to provide deeper analytical perspectives. The dashboards allowed visualization of customer demographics, behavioral patterns, and churn trends, helping to highlight key areas that required managerial attention.

Churn Prediction using Python

The predictive component of the project was implemented in Python, where a Random Forest classifier was trained to identify customers most likely to churn. The model’s output was integrated with the dashboards to provide a seamless view of both descriptive and predictive insights. This combination enabled not only understanding what had happened but also anticipating what might happen in the future.

Results and Insights

The analysis successfully identified the most influential factors contributing to customer churn. The predictive model provided actionable insights by flagging high-risk customers, and the Power BI dashboards enabled business-friendly interpretation of these results. Together, these tools demonstrated how organizations can move from raw data to data-driven decision-making.
